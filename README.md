# civic-llm-footprint

Code, benchmark and monitoring tool for the paper *LLM-Assisted Writing in Civic Participation: Multilingual Corpus-Level Estimation Across Platforms* (submitted to IEEE Access).

The framework estimates, at the **corpus level**, the share α of contributions to participation platforms (Decidim and
CONSUL open data, EU Have Your Say, U.S. Regulations.gov) that were written or rewritten with a large language model,
separately for each language and platform. It never classifies individual texts or authors.

## Method in brief

1. A multilingual classifier (XLM-RoBERTa-large, fine-tuned on pre-ChatGPT human texts against texts generated by twelve
   models) gives every text a score. Scores are cross-fitted in four folds, so that every score is out of sample.
2. The share of a slice is the mixing proportion that reproduces its score distribution as a mixture of the scores of
   the same platform's pre-ChatGPT texts and of generated texts (Hellinger-distance distribution matching, HDy).
3. A lower bound that uses the human score distribution only holds for any generator.
4. The interval of every estimate is the error band measured in forward validation (calibration on texts of 2020 and
   earlier, test on 2021–2022, generator held out).

A lexical distributional estimator, an excess-vocabulary indicator and three detectors with error correction are kept as
comparison methods.

## Layout

| Path | Content |
|---|---|
| `src/civic/ingest.py`, `collect_*.py` | Open-data exports (Decidim ZIP, GraphQL, CONSUL CSV, Have Your Say API, Mirrulations) → unified parquet with pseudonymised authors |
| `src/civic/preprocess.py` | Cleaning, language identification (lingua, with a second pass over all languages), lemma and POS tokens (spaCy) |
| `src/civic/generate.py` | Generated reference texts with vLLM or a commercial API (rewrite / generate / translate; audit scenarios) |
| `src/civic/study_scores.py` | Cross-fitted classifier scores of every text; final classifier for release |
| `src/civic/score_estimator.py` | HDy quantifier with per-instance calibration, generator-free lower bound, bootstrap |
| `src/civic/supervised_scores.py`, `scripts/quantify_scores.py` | Benchmark with the generator, vendor, mode or prompt held out; instance and forward-in-time protocols; alternative quantifiers |
| `scripts/calibrate_scores.py` | Interval calibrated on forward-validation errors and its coverage |
| `scripts/multitude_scores.py`, `scripts/raid_lb.py`, `scripts/intensity_scores.py` | External tests on archived outputs of 2023 (MULTITuDE, RAID) and on graded editing intensity |
| `src/civic/campaigns.py`, `src/civic/templates.py` | Coordinated campaigns: near-duplicate clusters (MinHash/LSH, BGE-M3) and letters assembled from shared sentences |
| `src/civic/analysis.py`, `consultations.py`, `scripts/study_extras.py` | Study: share per cell and per consultation, floors on pre-ChatGPT texts, time-series and mixed models, countries, description of high-scoring texts |
| `src/civic/estimator.py`, `benchmark.py`, `benchmark_robust.py`, `excess.py`, `detectors.py` | Comparison methods: lexical distributional estimator, excess vocabulary, Binoculars, Fast-DetectGPT, Open Pangram with Rogan–Gladen and Bayesian corrections |
| `src/civic/audit.py` | Failure-mode metrics L1–L7 on paired original and assisted texts |
| `src/civic/tool.py` | `analyze --url https://<decidim-instance>` → HTML report for administrations |
| `scripts/make_numbers.py`, `make_tables.py`, `make_cls.py`, `src/civic/figures*.py` | Every number, table and figure of the paper from the results directory |
| `scripts/lang_check.py`, `fix_data.py`, `fix_score_ids.py` | Data corrections of 10 November 2026 (wrong-language texts, seed identifiers), kept for traceability |
| `configs/` | Prompts (9 languages), audit scenarios, instance registry, generator registry, reference weights |

## Monitoring tool

```bash
python src/civic/tool.py analyze --url https://participa.example.org --out report/
```

The export is downloaded, pre-processed and scored with the released classifier (`models/xlmr_civic`). Each language is
calibrated on the instance's own texts written before 30 November 2022 (at least 300; otherwise on the human scores of the
language, which is less accurate) and on the scores of the generated reference texts (`models/refs`). The report lists, for
each year and contribution type, the estimated share with its calibrated interval and the generator-free lower bound.
The classifier and the reference files are distributed with the Zenodo record of the paper.

## Reproducing the study

```bash
uv venv .venv --python 3.11 && source .venv/bin/activate
uv pip install -r requirements.txt
# 1. data: ingest and pre-process every export
python src/civic/ingest.py --zip export.zip --instance mycity --out data/interim/mycity.parquet
python src/civic/preprocess.py --inp data/interim/mycity.parquet --out data/processed/mycity.parquet
# 2. generated reference texts (seeds: pre-ChatGPT texts)
python src/civic/generate.py sample --processed data/processed --out data/generated --n 1500
python src/civic/generate.py run --model Qwen/Qwen2.5-7B-Instruct --tag qwen2.5-7b \
    --sample data/generated/human_sample.parquet --out data/generated/gen_qwen2.5-7b.parquet
# 3. scores, benchmark, study (see scripts/chain_clean_gpu.sh and scripts/chain_clean_cpu.sh for the full sequence)
python src/civic/study_scores.py --processed data/processed/*.parquet --gen data/generated/generated_processed.parquet \
    --model xlm-roberta-large --out results/supervised/study_scores_aug.parquet --augment
python src/civic/analysis.py --processed data/processed/*.parquet --gen data/generated/generated_processed.parquet \
    --scores results/supervised/study_scores_aug.parquet --weights configs/reference_weights_vendor.yaml \
    --templates results/templates.parquet --out results/analysis_cls5
```

## Ethics

Estimates describe corpora. They must not be used to judge individual contributions or participants (see the guidelines
in the paper). Author identifiers are hashed with a salt at import time, and no text is redistributed.
